ZapFast 0.21.1-beta.8 (Znga) is the first release with a preview of ZapFast's new interface, built to look like WhatsApp Desktop for the Mac. ZapFast itself is unchanged from 0.21.1-beta.6.

## New

- **ZapFast Preview, the new interface, to try out.** Download a `zapfast-preview-*` file below to try it. It installs as **ZapFast Preview**, next to ZapFast, without replacing it. It opens your linked account with the same chats and settings, so there is nothing to link again.
- **What the preview does so far.** The chat list with search, filters, pins, favourites, mute, archive and read marks; conversations with text messages and replies; Archived, Starred and the Calls list; contact and group info; Settings, including the app lock, themes from your themes folder, a wallpaper image and the interface language; the tray, the Dock or taskbar badge with your unread chats, and start at login.
- **One ZapFast at a time.** ZapFast and ZapFast Preview use the same account, so they never run together: opening one while the other is running brings the running one forward instead. Quit ZapFast before you open the preview, and quit the preview before you go back.

## Known limitations

- The preview does not yet have message actions (react, forward, edit, delete), attachments, emoji, voice notes, media viewing, Znga, Insights or calls. Use ZapFast for these. Some text in the preview is still in English when another language is chosen.
- The preview does not update itself. Each beta comes with a new preview to download.
- The Mac and Windows packages are not code-signed. On a Mac, right-click the app and choose **Open** the first time.
- Calls are still a work in progress, as in upstream 0.21.1.

There is no 0.21.1-beta.7 release: its Windows preview failed to build, and this release carries the fix.
