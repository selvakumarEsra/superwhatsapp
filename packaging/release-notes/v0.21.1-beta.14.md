SuperWhatsapp 0.21.1-beta.14 returns to the interface of 0.21.1-beta.10 and finishes the move to the SuperWhatsapp name.

## What changes

- **Back to the 0.21.1-beta.10 interface.** The interface introduced in 0.21.1-beta.11 is set aside for now; this release is the 0.21.1-beta.10 app with Znga as a chat.
- **Your data lives under the SuperWhatsapp name.** Settings, chats and the archive are in `~/Library/Application Support/cc.superwhatsapp` on a Mac, `superwhatsapp` on Linux and `cc\superwhatsapp` on Windows. The archive keys are in the keychain under `cc.superwhatsapp`.
- **Upgrading keeps everything.** The first start of this release moves the folders and archive keys of 0.21.1-beta.10 or beta.11 over once. If you already ran beta.12 or beta.13, your data is already in place and is used as it is. Older folders are never read again after the move, and a new install never creates them.

## Known limitations

- If you ran beta.10 or beta.11 again after beta.12 or beta.13, that run's folder (`me.paolino.zapfast` on a Mac) is left alone: the newer `cc.superwhatsapp` folder wins. Quit SuperWhatsapp and move anything you need from the older folder by hand, or remove it.
- The macOS bundle ID stays `me.paolino.fastsapp` for this release so it updates in place; the next release switches it to `cc.superwhatsapp`.
- The Mac and Windows packages are not code-signed. On a Mac, right-click the app and choose **Open** the first time, and allow keychain access when asked.
